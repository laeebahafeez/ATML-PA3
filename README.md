python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate

Kaggle T4). Every analysis and figure script runs on CPU.

## Task 3 — Test-time compute

Stages 1–3 are CPU-only and run from the supplied rollouts.

```bash
python -m task3.data
```

Builds the 200/800 split, the ten nested rollout orders, and the answer
groups, writing `manifests/task3_split_*.json`, `manifests/task3_orders_*.npz`
and the cached pickles under `outputs/task3/`.

```bash
python -m task3.offline
```

```bash
python -m task3.adaptive
```

```bash
python -m task3.report
```

The live experiment needs a GPU:

```bash
python -m task3.live --questions manifests/task3_live_questions.json --out outputs/task3_live
```

```bash
python -m task3.live_analysis --calls outputs/task3_live/calls.jsonl --out results/task3/live
```

**Results.** `results/task3/summary_{math,mathvista}.csv` (accuracy, oracle
coverage, cost and group counts per method and budget),
`per_question_*.csv`, `selections_*.parquet`, `decomposition_*.csv`
(sampling vs selection failures), `signals_*.json` (quartile gaps,
length correlations, confidence–vision covariance, fusion ablation),
`adaptive.json` and `adaptive_*_{agreement,quality,fixed32}.csv`,
`bootstrap_*.json`, `examples.md`, `scorer_version.json`,
`live/summary.json`, `live/per_question.csv` and `live/calls.jsonl`
(every raw request and response from the live run).

Selection and stopping rules read **no gold answers and no unrevealed
candidates**: answer grouping in `task3/data.py` and `task3/math_groups.py`
runs before any label is attached, and `task3/adaptive.py` recomputes scores,
VisConf calibration and ranks from revealed candidates only. Gold answers are
used solely for scoring and for the analysis-only oracle-coverage curve.

## Reused external code

- **`task2/vqa_norm.py`** reimplements the answer-normalisation rules
  (punctuation, digits, articles, contractions) and the soft-accuracy formula
  of the official VQA evaluation script, released by the VQA authors under the
  MIT licence. The contraction and number tables are taken from that script;
  the surrounding code is original.
- **`lm-evaluation-harness`** (EleutherAI, MIT) is invoked as a library for all
  Task 1 benchmark numbers; `task1/evaluate.py` shells out to `lm_eval` and
  `task1/analyze.py` reads its `--log_samples` output.
- **`math-verify`** (Hugging Face, Apache-2.0) performs symbolic answer
  equivalence for MATH in `task3/data.py`.
- **`neurips_2026.sty`** is the course-provided NeurIPS style file.
- Model weights: `Qwen/Qwen3-0.6B` and `Qwen/Qwen2.5-3B-Instruct`
  (Alibaba, Apache-2.0); `google/siglip-base-patch16-224` (Google,
  Apache-2.0).
- Datasets: MetaMathQA, GSM8K, MATH, VQAv2, COCO and MathVista, cited in the
  report.

Everything else in this repository is my own work.
